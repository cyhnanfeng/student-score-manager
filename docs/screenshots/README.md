# 运行截图

本目录包含项目实际运行截图（JDK 18 + MySQL 8.4.3 控制台版），由程序真实运行后截取。

| 文件名 | 内容 |
| --- | --- |
| `01-login.png` | 登录界面 |
| `02-main-menu.png` | 登录成功后的主菜单 |
| `03-student-list.png` | 学生列表（5 条记录） |
| `09-course-list.png` | 课程列表（3 门课程） |
| `04-score-range-query.png` | 按分数段 90~100 查询（3 条记录） |
| `05-stat-by-course.png` | 按课程统计（平均分/最高分/最低分/及格率） |
| `06-stat-by-student.png` | 按学生统计 |
| `07-csv-export.png` | 查询全部成绩并导出 CSV |
| `08-csv-in-excel.png` | 用 Excel 打开导出的 CSV（中文无乱码） |

说明：

- 截图内容未经修改，数据来自 `sql/init.sql` 的初始数据。
- 部分截图中出现「检测到输入已结束，程序退出」，是因为自动化截图时标准输入被关闭，
  正常交互使用不会出现该提示。
